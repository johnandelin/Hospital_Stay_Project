# Hospital Admission 
This project was done for an Introduction to Computer Science class at Brigham Young University. It uses machine learning to predict the total number of hospital admissions using a dataset from Kaggle, which includes hospital admission records from Riyadh between 2020 and 2024.

The main goal was to build a working predictive model rather than aiming for perfect accuracy. This project gave me hands-on experience with preprocessing real-world healthcare data, feature engineering, and testing different machine learning algorithms.

The project includes:

- Random Forest Regressor – tuned with cross-validation

- K-Nearest Neighbors (KNN) – scaled and tuned for optimal performance

- Stacked Ensemble – combines Random Forest and KNN using a linear regression as the final estimator

I also created visualizations comparing predicted versus actual admissions and residual plots for all models. This project is meant as a starting point, and I plan to continue refining the models in the future.
